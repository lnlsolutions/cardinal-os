# Cardinal OS — agency operating system demo

Single-file simulation for the Cardinal Insurance Group meeting.
Open `index.html`. Access code: `cardinal2026`.

What it demonstrates end to end:
- Dashboard: book of business, renewals at risk, today's queue, spend and lead source
- Clients: one record per household, click through to a 360 view with every carrier
- Client 360: policies per carrier, ID card, certificate of insurance, declarations page, payment, pull from carrier
- Quotes: rate across markets, select, bind, policy issued
- Policies: renewals, payment status, lapse risk
- Tasks: follow-up queue plus out-of-office coverage handoff
- Campaigns: nurture, quote follow-up, renewal save, payment reminder, birthday, cross-sell
- Growth: spend, CPL, quote rate, cost per bound policy, lead flow, ZIP density
- Data sync: EZLynx pull, carrier portals, website lead forms
- Security: how the production deployment protects client data

All records are synthetic. No live policyholder data is present in this repo.
